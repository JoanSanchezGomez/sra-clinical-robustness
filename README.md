This repository contains the code associated with the paper:
"Clinical Reliability Assessment of Medical AI Models Using the SRA Method: Quantifying Risk from Clinical Correlation Bias"
Juan Manuel Sánchez Gómez, Ginés García-Mateos, Rubén Fernández-Beltrán
University of Murcia, Spain

Code will be made available upon acceptance of the paper.

Abstract
We propose the SRA (Systemic Relationship Analysis) method and its associated metric F1-RS (F1-Robustness Score), which quantifies the degradation range between the easiest and hardest diagnostic contrasts identified from confusion-matrix analysis. The method was applied to three representative architectures — EfficientNet-B0, ConvNeXt-Base, and Swin Transformer Tiny — on two ophthalmological datasets (EDC and ODIR-5K).
